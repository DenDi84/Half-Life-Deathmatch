Requires [Half-Life SWEPs](https://steamcommunity.com/sharedfiles/filedetails/?id=1360233031), [GoldSrc HUD](https://steamcommunity.com/sharedfiles/filedetails/?id=1290525688) and [Half-Life: Source Playermodels](https://steamcommunity.com/sharedfiles/filedetails/?id=107768377) for correct working.
